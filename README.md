Попытка использования OpenSource инструментов oss-cad-suite Yosys + Icarus. Для использования скачать нужную версию с https://github.com/YosysHQ/oss-cad-suite-build/releases, распаковать в папку. Папка данного репозитория должна располагаться на одном уровне иерархии с корневой папкой oss-cad-suite

Для запуска синтеза запустить synth.bat
